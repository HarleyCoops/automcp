# JSONPlaceholder MCP Server

This MCP server exposes convenient tools for the target REST API.

## Endpoints

| Name | Method | Path | Description |
| ---- | ------ | ---- | ----------- |
| root_request | GET | / | Fetch the root of the API to verify connectivity. |

Base URL: https://jsonplaceholder.typicode.com

## Development

```bash
npm install
npm run build
npm start
```
